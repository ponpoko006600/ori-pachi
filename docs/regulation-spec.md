# オリパチ 規制計算仕様表

最終更新: 2026-05-14

この資料は、オリパチの「総量規制チェック」を実機の考え方に近づけるための仕様表です。

## 重要な前提

パチンコの規制は、大きく分けて次の2層で考える必要があります。

| 区分 | 内容 | オリパチでの扱い |
| --- | --- | --- |
| 公開法令・技術上の規格 | 遊技機の型式試験で見る正式な上限・下限。出玉率、賞球、発射性能など。 | 「公式に確認できる硬い数値」として扱う |
| 業界内規・運用ルール | 総量規制、LT上限、LT比率など。全文は一般公開されていない可能性が高い。 | 公開情報から確認できる範囲で、サイト内の安全側チェックとして扱う |

そのため、オリパチでは「検定適合を保証する」ではなく、「公開情報ベースで規制を大きく外れないスペック試算をする」サービスとして表現する。

## 1. 公開法令ベースの公式値

根拠: 遊技機の認定及び型式の検定等に関する規則、警察庁公開資料。

| 項目 | 数値 | 計算・意味 | オリパチ実装方針 |
| --- | ---: | --- | --- |
| 発射速度 | 1分間100発以下 | 1時間なら最大6,000発を打ち出す前提になる | 法令試験の換算に使う |
| 1入賞あたり賞球 | 最大15個 | 15個賞球が現在の最大払い出し単位 | 1回の内部大当たりは最大1,500発として扱う |
| 大当たり1回の最大払い出し | 1,500発 | 15賞球 × 10カウント × 10R | 3,000発や7,500発は「1,500発の複数回セット」として表現する |
| 短時間出玉率 | 1/3以上、2.2以下 | 約1時間試験の出玉率。6,000発打ち出しなら払い出し約2,000〜13,200発相当 | 将来の詳細試験モードで使う |
| 中時間出玉率 | 2/5以上、1.5以下 | 約4時間試験の出玉率。24,000発打ち出しなら払い出し約9,600〜36,000発相当 | 将来の詳細試験モードで使う |
| 長時間出玉率 | 1/2以上、4/3以下 | 約10時間試験の出玉率。60,000発打ち出しなら払い出し約30,000〜80,000発相当 | 将来の詳細試験モードで使う |

注意:

- 上の出玉率試験は、本来は遊技機の構造、役物、入賞口、作動タイミング、試射条件などを含めて確認するもの。
- オリパチの入力項目だけでは完全再現できないため、現時点では「法令試験に近い簡易チェック」として扱う。

## 2. 総量規制・LT内規ベースの仕様

公開情報で確認できる範囲では、現在のパチンコLTまわりは以下の数値で管理するのが妥当。

| 規制タイプ | 対象 | 上限・条件 | オリパチ実装方針 |
| --- | --- | --- | --- |
| LTなし | 旧来型・非LT | RUSH/確変の期待出玉はおおむね6,400発未満を目安 | 通常RUSH期待出玉が6,400発以上なら警告 |
| LTあり | LT搭載機 | LT突入時の期待出玉は9,600発未満を目安 | LT期待出玉が9,600発以上なら規制オーバー |
| LTあり | 初当たり全体 | 初当たりを含む期待出玉は6,400発未満を目安 | 初当たり1回あたり期待出玉が6,400発以上なら規制オーバー |
| LTあり | LT比率 | 獲得期待出玉のうちLTが占める割合は80%以下を目安 | LT期待出玉 / 総期待出玉 が80%超なら規制オーバー |
| LT3.0プラス | スマパチ中心 | 2025年以降の新しいLT運用。最大出玉性能の考え方が広がる | 今後、必要に応じて別タイプとして追加 |

実装上は「未満」の数値は安全側に倒し、`6400発ちょうど` や `9600発ちょうど` をOKにせず、少し下回る必要があるものとして扱うのが望ましい。

## 3. オリパチで使う期待出玉計算

### 3.1 出玉振り分けの平均

```text
平均出玉 = Σ(出玉数 × 振り分け率)
```

例:

```text
1,500発 50%
3,000発 50%

平均出玉 = 1500 × 0.5 + 3000 × 0.5 = 2250発
```

### 3.2 ST中の継続率

右打ち中確率とST回数から計算する場合:

```text
ST継続率 = 1 - (1 - 1 / 右打ち中確率分母) ^ ST回数
```

例:

```text
右打ち中確率 1/99
ST 163回

ST継続率 = 1 - (98 / 99) ^ 163
```

### 3.3 RUSH期待出玉

1段階RUSHの場合:

```text
RUSH期待出玉 = RUSH中平均出玉 / (1 - RUSH継続率)
```

例:

```text
RUSH中平均出玉 1,500発
継続率 75%

RUSH期待出玉 = 1500 / (1 - 0.75) = 6000発
```

### 3.4 2段階RUSH

```text
上位RUSH期待出玉 = 上位RUSH平均出玉 / (1 - 上位RUSH継続率)

下位RUSH期待出玉 =
  (下位RUSH平均出玉 + 下位継続率 × 上位昇格率 × 上位RUSH期待出玉)
  / (1 - 下位継続率 × (1 - 上位昇格率))
```

### 3.5 3段階RUSH

```text
初当たり後
  → RUSH突入抽選
  → 中位RUSH抽選
  → 上位/LT抽選
  → 各段階の期待出玉を合算
```

オリパチでは3段階RUSHを、以下の順で計算する。

```text
下位RUSH期待出玉
中位RUSH期待出玉
上位/LT期待出玉
初当たり1回あたり総期待出玉
```

### 3.6 突入時短の引き戻し

非突入時に時短がある場合:

```text
時短引き戻し率 = 1 - (1 - 1 / 通常時大当たり確率分母) ^ 時短回数
```

実質RUSH突入率:

```text
実質RUSH突入率 =
  直RUSH突入率
  + (1 - 直RUSH突入率) × 時短引き戻し率 × 引き戻し後RUSH突入率
```

## 4. オリパチの規制チェック仕様

### LTあり

| チェック | NG条件 | 原因として赤表示する項目 |
| --- | --- | --- |
| LT期待出玉 | LT期待出玉 >= 9,600発 | LT継続率、上位/LT出玉、上位突入率 |
| 初当たり総期待出玉 | 初当たり1回あたり総期待出玉 >= 6,400発 | RUSH突入率、継続率、出玉振り分け |
| LT比率 | LT期待出玉 / 総期待出玉 > 80% | RUSH構造、LT継続率、出玉振り分け |
| 1回の内部大当たり | 内部1回あたり1,500発超 | 出玉ティア |

### LTなし

| チェック | NG条件 | 原因として赤表示する項目 |
| --- | --- | --- |
| RUSH期待出玉 | RUSH期待出玉 >= 6,400発 | RUSH突入率、RUSH継続率、出玉振り分け |
| 継続率 | 継続率 > 81% | RUSH継続率、ST回数、右打ち中確率 |
| 1回の内部大当たり | 内部1回あたり1,500発超 | 出玉ティア |

## 6. 今後の実装優先度

| 優先度 | 内容 | 理由 |
| --- | --- | --- |
| 高 | 6400発/9600発を「未満」判定に変更 | ちょうど上限をOKにしないため |
| 高 | 1,500発超の出玉を内部回数として扱うUIを明確化 | 3,000発、6,000発、7,500発を実機らしく表現するため |
| 中 | 右打ち中確率 × ST回数から継続率を自動計算 | 実機スペックに近づけるため |
| 中 | 突入時短引き戻しを総期待出玉へ反映 | エヴァ15系の再現精度を上げるため |
| 低 | 法令試験モード | 1時間/4時間/10時間試験は入力項目が多く、初心者向けUIと相性が悪いため |
